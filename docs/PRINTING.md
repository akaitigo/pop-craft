# 印刷・PDF保存ガイド

## 対応用紙

| 用紙 | CSS用紙サイズ | 印刷Canvas（300 DPI） |
|---|---:|---:|
| A4 | 210mm × 297mm | 2480px × 3508px |
| A5 | 148mm × 210mm | 1748px × 2480px |
| 名刺 | 91mm × 55mm | 1075px × 650px |

画面プレビューは表示領域へ縮小しますが、印刷時は上表のCanvasをmm単位の用紙領域へ配置します。文字サイズは420px幅を基準に印刷Canvasへ比例拡大します。

## 利用者が指定する設定

ブラウザの印刷画面で次を指定してください。

1. アプリで選んだものと同じ用紙サイズ
2. 倍率100%
3. 余白なし
4. 背景グラフィックを印刷

プリンタがフチなし印刷に対応しない場合、ハードウェア固有の非印字領域で端が欠けることがあります。重要な文字は端へ配置しない設計を維持してください。

## Webフォントの扱い

印刷プレビューは選択中の日本語Webフォントを最大5秒待ってからCanvasを描画します。読込失敗・タイムアウト・Font Loading API非対応時は端末の代替フォントで描画し、印刷前に警告を表示します。印刷ボタンを押した時点でもフォントを再確認します。

## 実ブラウザ検証（2026-07-20）

Chrome for Testing 147 / LinuxのDevTools `Page.printToPDF`で`preferCSSPageSize`を有効にし、次を確認しました。

| 用紙 | PDF MediaBox（pt） | ページ数 | 日本語描画 |
|---|---:|---:|---:|
| A4 | 594.96 × 841.92 | 1 | 確認済み |
| A5 | 420.00 × 594.96 | 1 | 確認済み |
| 名刺 | 258.00 × 156.00 | 1 | 確認済み |

PDFの1ptは1/72インチです。ブラウザの丸めにより理論値と小数点以下の差があります。

FirefoxとSafariはこの検証環境に実行可能なブラウザがなく、未検証です。公開前に各ブラウザで同じ用紙・1ページ・日本語・背景色・余白を手動確認してください。SafariはmacOS実機で確認します。

## 回帰検証

```bash
cd frontend
pnpm test -- --run src/lib/print.test.ts src/lib/canvas/fonts.test.ts src/components/PrintPreview.test.tsx
pnpm build
```

自動テストは用紙ごとの300 DPI寸法、mm指定、無効用紙のA4 fallback、フォント成功・失敗・タイムアウト、印刷前の再読込を対象にします。ブラウザの印刷ダイアログと物理プリンタは自動テスト範囲外です。
